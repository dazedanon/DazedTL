# WolfDawn bundled binaries

Source: <https://gitgud.io/zero64801/wolfdawn>

`python -m util.wolfdawn.update_tools --refresh-all` builds both platform binaries from upstream `master` and records the commit each was built from in [`.wolf_version.json`](../.wolf_version.json).
