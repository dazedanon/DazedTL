## Character identity and terminology safeguards

- Build glossary coverage from the whole reviewed source corpus, including recurring entities
  mentioned only in dialogue, unseen characters, deities, titles and coined terms. Check frequently
  repeated names that have no glossary entry before translating; speaker lists alone are incomplete.
- Record gender only when the source establishes it. Mark unresolved or deliberately concealed
  gender as unknown. Never infer it from a name, speech register, or an English title. Preserve
  deliberate uncertainty with neutral wording and record the scope of any later reveal.
- Record confirmed aliases, but keep public names, disguises, anonymous speakers and revealed
  identities separate when normalizing them would spoil the story. State when each name applies;
  never merge two entries merely because they ultimately identify the same person.
- When characters address someone by a role or title, record the address form as well as the nameplate label.
  Search the dialogue for that title with an honorific, and give each observed form its own row directly after the title's row: `隊長さん (Captain-san) - How the cast addresses the Guard Captain; the nameplate stays Guard Captain.`
  Translate only the title the speaker says plus its honorific, without the words the label adds to tell roles apart.
  A bare title used as a call has the same source as the label row, so state its English address in that row's note instead of adding a second row.
  Translation follows a row's parenthesized English, so a note such as "distinguish direct address from the role label" does not change how the title is addressed.
  Leave kinship and generic person words such as `おじさん` to the base glossary.
- Keep each character's register distinct from gender. Give concrete voice cues and document
  apparent contradictions so a feminine register does not silently change a male character's pronouns.
- Before accepting a glossary change, check dialogue, names, UI labels and already-lettered images
  that use the term. Update affected outputs together; do not fix terminology in only one track.
