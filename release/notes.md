### Fixed

- **Settings:** a Claude model the price list doesn't know, named with OpenRouter's dotted version, such as `anthropic/claude-opus-4.5` or `anthropic/claude-opus-5.5`, now takes its own per-token price instead of an older Claude Opus's, and Claude 3 Opus's and Claude 3.5 Haiku's dated IDs, such as `claude-3-opus-20240229`, take theirs instead of Sonnet's or a newer Haiku's.
- **Translate:** a Claude model named as Vertex AI, Databricks or a Bedrock ARN name it, such as `vertex_ai/claude-sonnet-5-5`, `databricks-claude-sonnet-4` or `arn:aws:bedrock:...:inference-profile/us.anthropic.claude-...`, now counts as Claude, with Claude's prices and the note that its estimate leaves out thinking.
- **Translate:** a Claude connection whose address only holds Anthropic's name, such as `https://anthropic.company.example`, no longer sends Message Batches there or refuses another host's Claude name as Anthropic's own API would; only Anthropic's own address counts as its API.
- **Translate:** an NScripter game's choices (`csel`) are now written with their own translation, where each choice was replaced with the dialogue line translated before it, and a file whose choices come before any dialogue no longer fails.
- **Translate:** an RPG Maker plugin file with a quest name (`QuestName`) before any `txtSubject` line, or after one without a line break, no longer fails, and a quest name's own line break is now sent as a space.
- **Translate:** an NScripter file with choices (`csel`) but no dialogue lines now translates its choices instead of leaving them in Japanese, and a choice that is part of a later one, such as はい before はいはい, or an empty choice `""` no longer corrupts the `csel` line.
- **Translate:** an RPG Maker plugin file keeps a lowercase actor name code such as `\n[1]` or a name box code such as `\n<Alice>` in `txtSubject`, quest name and other plugin text, where it was read as a line break and lost, and a quest client, location or place with a line break now sends it as a space, as quest names do.
- **Translate:** a CSV file has no speaker column unless one is chosen, where the target column was read as each row's speaker, so a row whose target held text was sent with it as a speaker name and each row's translation was written to the next row; a speaker column set to the target column no longer shifts translations either.
- **Images:** translating image text no longer writes its translations over the run's saved record of the text it sent, which made a later start of that run stop with "An input changed after planning".
- **Settings:** a Claude model ID in capitals, such as `Claude-Opus-5`, saved for Anthropic's own API is now refused with its lowercase ID named, such as `claude-opus-5`, since Anthropic lists its IDs in lower case, and a new run with one no longer starts; a run already created with one still resumes.
- **Translate:** Claude Opus 5.5, Sonnet 5.5, Fable 5.1 and Mythos 5.1 named with a dotted version, such as `claude-opus-5.5`, now price their cache reads at their own rate instead of a tenth of input, so their spending and quotes no longer read too high.
- **Translate:** a Kirikiri, Tyrano, Lune, CSV, Regex or WOLF RPG 2 game no longer pays a second time for each speaker name, which was sent again once it held its translation and could be renamed by that reply; a WOLF RPG 2 game's choices are no longer translated twice either.
- **Translate:** a Lune file is now translated whatever its name, where any file not named `.json`, such as the `.l` files the engine offers, failed with "Not Supported".
- **Translate:** a Guided Live request whose answer may have been billed, such as one a gateway timed out with HTTP 502, 504 or 524, is now sent once and reads uncertain under **Check submission** while the run goes on with its other requests, instead of up to 15 times, or more on Mistral, which a paid provider behind a proxy could charge for each time; a request the provider did not process, one that could not connect, met a rate limit or got a preset provider's own server error, is still sent again, up to 5 times, waiting as long as the provider asks, up to a minute.
- **Translate:** a Guided run's file costs and total now count each request's cost once, whatever Stop, Resume or a retry read again: a Batch request two files share counted twice, a file translated after an earlier attempt failed, or a Batch save retried after a reply failed, kept only the last attempt's cost, and requests answered just before a Live run stopped, or before a Batch save missed a later result, were left out; a file's time now adds up what each attempt spent on it.
- **Translate:** a connection whose address only holds Gemini's, such as a proxy at `https://proxy.example/generativelanguage.googleapis.com/v1beta/openai/`, no longer sends Batches straight to Google past the proxy; only Gemini's own address counts as its API, and an address typed without `https://`, such as `openrouter.ai/api/v1`, now reads as its provider's for model lists and evaluation prices.
