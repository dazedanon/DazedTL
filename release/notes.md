### Fixed

- **Settings:** a Claude model the price list doesn't know, named with OpenRouter's dotted version, such as `anthropic/claude-opus-4.5` or `anthropic/claude-opus-5.5`, now takes its own per-token price instead of an older Claude Opus's, and Claude 3 Opus's and Claude 3.5 Haiku's dated IDs, such as `claude-3-opus-20240229`, take theirs instead of Sonnet's or a newer Haiku's.
- **Settings:** a Claude model ID in capitals, such as `Claude-Opus-5`, saved for Anthropic's own API is now refused with its lowercase ID named, such as `claude-opus-5`, since Anthropic lists its IDs in lower case, and a new run with one no longer starts; a run already created with one still resumes.
- **Translate:** a Claude model named as Vertex AI, Databricks or a Bedrock ARN name it, such as `vertex_ai/claude-sonnet-5-5`, `databricks-claude-sonnet-4` or `arn:aws:bedrock:...:inference-profile/us.anthropic.claude-...`, now counts as Claude, with Claude's prices and the note that its estimate leaves out thinking.
- **Translate:** every Claude request now goes to its connection's address, read one way: a Guided Live send and its refusal clarification no longer go to Anthropic's default address whatever the address says, a Batch or evaluation saved without an address no longer follows an `ANTHROPIC_BASE_URL` set where the app was started, and an address ending in `/v1` is no longer sent `/v1/v1/...` by Batches and model lists.
- **Translate:** a connection whose address only holds Gemini's, such as a proxy at `https://proxy.example/generativelanguage.googleapis.com/v1beta/openai/`, no longer sends Batches straight to Google past the proxy; only Gemini's own address counts as its API, and an address typed without `https://`, such as `openrouter.ai/api/v1`, now reads as its provider's for model lists and evaluation prices.
- **Translate:** Claude Opus 5.5, Sonnet 5.5, Fable 5.1 and Mythos 5.1 named with a dotted version, such as `claude-opus-5.5`, now price their cache reads at their own rate instead of a tenth of input, so their spending and quotes no longer read too high.
- **Translate:** an OpenRouter cost estimate, or an Assistant-led quote waiting for approval, keeps its OpenRouter Batch price while the model's prices can't be read, such as after the connection's check failed, where its Batch estimate showed half its Live price or disappeared.
- **Translate:** an NScripter game's choices (`csel`) are now written with their own translation, where each choice was replaced with the dialogue line translated before it; a file whose choices come before any dialogue no longer fails, one with choices but no dialogue lines now translates them instead of leaving them in Japanese, and a choice that is part of a later one, such as はい before はいはい, or an empty choice `""` no longer corrupts the `csel` line.
- **Translate:** an RPG Maker plugin file with a quest name (`QuestName`) before any `txtSubject` line, or after one without a line break, no longer fails; it keeps a lowercase actor name code such as `\n[1]` or a name box code such as `\n<Alice>` in `txtSubject`, quest names and other plugin text, where it was read as a line break and lost, and a line break in a quest name, client, location or place is now sent as a space.
- **Translate:** an RPG Maker plugin file's color codes, such as `\\C[2]` in `txtSubject` or `\c[2]` in a quest summary (`QuestContent`), are now written back with as many backslashes as the file uses, where they were written with one and showed as text such as `C[2]` in the game; a line break in a `txtSubject` translation is no longer written as a color code or a raw line break.
- **Translate:** a CSV file has no speaker column unless one is chosen, where the target column was read as each row's speaker, so a row whose target held text was sent with it as a speaker name and each row's translation was written to the next row; a speaker column set to the target column no longer shifts translations either.
- **Translate:** a Kirikiri speaker line and a CSV file's `:name[]` tag now have only the name itself translated, where the name was also replaced in the rest of the line or in the dialogue after the tag, such as a voice file named after the speaker; a CSV row whose target already holds the text, or whose name is translated with a `]`, now has its dialogue translated instead of kept in Japanese.
- **Translate:** a Kirikiri, Tyrano, Lune, CSV, Regex or WOLF RPG 2 game no longer pays a second time for each speaker name, which was sent again once it held its translation and could be renamed by that reply; a WOLF RPG 2 game's choices are no longer translated twice either.
- **Translate:** a WOLF RPG 2 speaker name translated with a `/`, such as `Al/Ice`, no longer moves the translations after it to the wrong lines, and a WOLF RPG 2 file holding bytes none of its encodings read now keeps its line breaks, where its blank lines were lost and the whole file was sent and written as one line.
- **Translate:** a Lune file is now translated whatever its name, where any file not named `.json`, such as the `.l` files the engine offers, failed with "Not Supported".
- **Translate:** a Lune file with an entry holding two text fields, such as `text` and `message`, now writes each translation to its own entry and field, where the entry after it was skipped and the translations after it landed on the wrong entries; after a reply with the wrong number of lines, the next batch's translations no longer land one entry early.
- **Translate:** a Guided Live request whose answer may have been billed, such as one a gateway timed out with HTTP 502, 504 or 524, is now sent once and reads uncertain under **Check submission** while the run goes on with its other requests, instead of up to 15 times, or more on Mistral, which a paid provider behind a proxy could charge for each time; a request the provider did not process, one that could not connect, met a rate limit or got a preset provider's own server error, is still sent again, up to 5 times, waiting as long as the provider asks, up to a minute.
- **Translate:** a Guided run's file costs and total, and those of a Batch imported from the original tool, now count each request's cost once, whatever Stop, Resume or a retry read again: a Batch request two files share counted twice, a file translated after an earlier attempt failed, or a Batch save retried after a reply failed, kept only the last attempt's cost, and requests answered just before a Live run stopped, or before a Batch save missed a later result, were left out; a file's time now adds up what each attempt spent on it.
- **Translate:** an Assistant-led Live request or clarification that could not connect to the provider now reads failed, saying the provider could not be reached, instead of uncertain, so it no longer blocks further paid work until reviewed.
- **Translate:** a Claude Live request that Anthropic ends with an overload after it starts answering now reads failed instead of uncertain and, in a Guided run, is sent again as an overload before its answer is, since Anthropic does not charge for it.
- **Translate:** a Mistral rate limit that outlasts every retry in a run started with an earlier version now shows Mistral's own status and message instead of only "Mistral API failed after 7 attempts".
- **Images:** translating image text no longer writes its translations over the run's saved record of the text it sent, which made a later start of that run stop with "An input changed after planning".
- **Translate:** a Claude connection whose address only holds Anthropic's name, such as `https://anthropic.company.example`, no longer sends Message Batches there or refuses another host's Claude name as Anthropic's own API would; only Anthropic's own address counts as its API, and a Custom OpenAI-compatible connection at such an address can now run Claude models, where Settings refused it with "The model and server use a different provider route".
- **Translate:** a Batch saved with an API key but no server address no longer sends that key to the current connection's server when its status is read; it asks for its connection to be restored in Settings instead.
- **Translate:** a Claude estimate whose token count from Anthropic failed, such as through a proxy without token counting, now asks Anthropic again on the run's next estimate instead of keeping the rougher count.
