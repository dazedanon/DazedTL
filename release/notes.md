### Changed

- **Compare:** the page is one workspace instead of three tabs: each column is a model with its own thinking effort, glossary and instruction, so you can try two settings of one model side by side; a column translated before with the same lines and settings is reused instead of paid for again, **Mark differences** marks each column's changes from the first, and a running comparison shows one status line with **Stop**.
